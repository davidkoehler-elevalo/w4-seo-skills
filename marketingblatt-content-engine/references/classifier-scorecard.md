# Classifier scorecard (NEW — from the Paoli process)

A pre-publish "is this actually competitive?" gate. Score the draft on the influenceable ranking
levers (the ones content work can move), /10 each, then a composite. Below a strong composite, or with
an obvious weak lever, revise before publishing. This is judgement, not a fetch — score honestly.

## Levers (score /10, with what earns a high score)

| Lever | What earns a high score |
|---|---|
| `contentEffort` | Genuine depth: substantial word count for the intent, real data, primary-study citations, a proof case, a useful FAQ. Not padding. |
| `OriginalContentScore` | Information gain: several angles beyond the commodity SERP/AI-Overview (the `beyond_insights`). No short-page trigger. |
| `titlematchScore` | Title leads with the head keyword; H1/title and the URL slug match the head term. |
| `isAuthor` (E-E-A-T proxy) | Named author (David Koehler) + credible sender ("wir sehen in Kundenprojekten"). Real experience signals, no faked ones. |
| `lastSignificantUpdate` | Genuine, substantive content (for refresh: a real rewrite with an updated visible date, not a date bump). |
| `NavBoost` / long-click setup | Lead-with-answer, scannable structure, intro box, FAQ — the setup that earns long clicks. Realised post-publish; score the setup. |
| `siteFocusScore` | Squarely on-topic for a HubSpot/B2B-marketing blog; no sprawl; handoff links instead of chasing off-topic terms. |
| `pandaDemotion` (inverse) | Substantive, accurate, sourced — not thin, duplicate, or cannibalising. |

## Composite & verdict
- Average the levers. Treat **≥ 8.0** as best-in-class, **6.5-7.9** as ship-with-notes, **< 6.5** as
  revise before checkpoint 2.
- Always write two honest caveats, Paoli-style:
  1. **AI Overview cap** — for pure-answer head terms, clicks are capped no matter how good the page
     is; the realistic wins are top-3 organic, AIO *citation*, and the commercial / long-tail FAQ
     terms where nuance still earns a click.
  2. **Conditional levers** — note which scores depend on things outside the draft (e.g. the visible
     publish date, internal links actually shipping, author entity setup).

## Relation to the KB gate
The KB gate (`kb-strategy.md`) checks alignment and active harm. The classifier scorecard is the
complementary "is it strong enough to win" view. Both must pass before checkpoint 2: no open HIGH harm
flag, and a composite that is at least ship-with-notes.
